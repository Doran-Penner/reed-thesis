# Prolly Trees for State-Based CRDTs

This is my undergraduate thesis for Reed College, expected graduation in May 2026.
Thanks to [Samasaur1](https://github.com/Samasaur1) for the template; I'm glad I don't need to use raw latex for everything.
Licensing is awkward because this is a mix of "code stuff" (build template and such) and "creative stuff" (main content). I choose to put the whole repository under the MIT license and hope that it's sufficient.
You can build the pdf yourself: `quarto render --to pdf` will make the main content but not include the git hashes, while `nix build .#thesis` takes longer but adds the git repo data.
